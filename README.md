# Extensão VII – Programação Básica em Python

## Sobre o projeto

Este repositório apresenta o material do projeto de Extensão VII, desenvolvido com o objetivo de introduzir conceitos básicos de programação utilizando a linguagem Python.

O curso foi organizado em videoaulas, com conteúdos progressivos e exemplos práticos para pessoas que estão iniciando na programação.

## Conteúdo do curso

- Introdução – Apresentação do curso
- Aula 01 – Introdução à programação
- Aula 02 – Conhecendo o Google Colab
- Aula 03 – Primeiro programa, print() e comentários
- Aula 04 – Variáveis
- Aula 05 – Tipos de dados
- Aula 06 – Entrada de dados com input()
- Aula 07 – Operadores matemáticos
- Aula 08 – Estruturas condicionais
- Aula 09 – Repetições e listas
- Aula 10 – Projeto final: calculadora interativa

## Objetivo

Disponibilizar conteúdos introdutórios de programação de forma acessível, contribuindo para o desenvolvimento do pensamento lógico e dos conhecimentos básicos em Python.
